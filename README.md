# Пульс сервиса

Статический демонстрационный портал обучения для сервисной команды. Интерфейс содержит вход с псевдонимом, каталог учебных модулей, короткий тест, анонимную оценку формата и экран результатов.

## Приватность

Сайт не использует сервер, базу данных, API, аналитику или внешние трекеры. Демо-сессия, псевдоним, отметки модулей, лучший результат теста и оценка сохраняются в одной cookie на 30 дней и остаются только в браузере посетителя.

Это не настоящая система авторизации и не подходит для защиты контента или хранения персональных данных.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm test
npm run typecheck
npm run build
```

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает `dist/` после каждого push в `master`.

1. Закоммитьте и отправьте файлы в `Antonpavlov-io/site`.
2. Откройте **Settings → Pages** в GitHub-репозитории.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. После завершения workflow сайт будет доступен по адресу `https://antonpavlov-io.github.io/site/`.
